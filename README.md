## Sobre o projeto

O **UTFuel** é um projeto multidisciplinar voltado ao desenvolvimento de uma plataforma própria de eletrônica e sistemas embarcados para aplicações automotivas.

O projeto busca integrar estudantes principalmente das áreas de:

- Engenharia Elétrica;
- Engenharia Mecânica;
- Ciência da Computação;
- Análise e Desenvolvimento de Sistemas;
- áreas relacionadas a sistemas embarcados, controle e desenvolvimento tecnológico.

O desenvolvimento será realizado de forma gradual, iniciando por estudos, levantamento de requisitos, prototipagem, aquisição de dados, comunicação entre sistemas e testes em bancada.

No longo prazo, o objetivo é desenvolver uma plataforma capaz de realizar funções de gerenciamento eletrônico automotivo, aquisição de dados, diagnóstico, telemetria e outras aplicações experimentais.

---

## Objetivo

Desenvolver uma plataforma acadêmica de sistemas embarcados automotivos composta por hardware, firmware e software próprios, permitindo:

- formação prática dos estudantes;
- desenvolvimento tecnológico;
- experimentação;
- pesquisa aplicada;
- atividades de extensão;
- integração com projetos veiculares da universidade;
- compartilhamento de conhecimento com a comunidade.

---

## Situação atual

**Fase:** Estruturação inicial / Proof of Concept

Atualmente o projeto encontra-se nas etapas de:

- formação da equipe;
- levantamento de requisitos;
- organização da documentação;
- definição da arquitetura;
- desenvolvimento das primeiras ferramentas;
- planejamento da bancada de testes;
- estruturação para homologação como projeto de extensão.

> A UTFuel ainda não deve ser considerada uma ECU pronta para utilização em veículos.

---

## Desenvolvimento incremental

O projeto será desenvolvido em etapas.

### Fase 0 — Estruturação

- organização da equipe;
- levantamento de requisitos;
- documentação;
- definição dos padrões de desenvolvimento;
- escolha inicial das tecnologias.

### Fase 1 — Prova de conceito

- leitura de sensores;
- comunicação CAN;
- comunicação com computador;
- simulador de sinais;
- datalog;
- primeiros protótipos eletrônicos.

### Fase 2 — Bancada

- hardware próprio;
- firmware embarcado;
- simulador de motor;
- UTFuel TestBench;
- testes automatizados;
- diagnóstico e validação.

### Fase 3 — Controle experimental

- controle de atuadores;
- sincronismo;
- estratégias de gerenciamento;
- testes com cargas reais;
- validação em ambiente controlado.

### Fase 4 — Integração veicular

- testes em paralelo com sistemas existentes;
- integração CAN;
- aquisição de dados;
- validação progressiva em veículo.
